1. Project Background

SmartRPD is an AI-assisted dental design platform that automates the planning and fabrication of Removable Partial Dentures (RPDs). An RPD is a prosthetic device used to replace missing teeth; its design requires precise mapping of a patient's dental arches, identification of anatomical features, and placement of metal framework components such as clasps, rests, major connectors and mesh.

The existing SmartRPD desktop application runs a full AI inference pipeline: it processes CBCT scan data to produce jaw mesh models (OFF/STL geometry), detects anatomical landmarks, segments individual teeth, generates guide polylines for RPD component placement, and positions artificial teeth. Dental technicians and supervising clinicians then review, annotate, and approve the AI output before sending designs for manufacture.

The web client is the browser-based complement to this desktop system. It was commissioned to remove the requirement for the full desktop installation for clinicians performing reviews, approvals, and case communications. The project scope covers two closely integrated modules:

  • 3D Web Viewer — A Three.js-based viewer for AI-generated jaw meshes, RPD design overlays and analysis heatmaps (Shafik's primary deliverable).
  • 2D Annotation Workspace & Case Workflow — A browser-based RPD component editor, case management portal, clinical notes, and report generation (Nyunt's primary deliverable).

Both modules connect to the live SmartRPD REST API (live.api.smartrpdai.com), share a common authentication and navigation shell, and are deployed together on GitHub Pages and a Docker/Nginx stack for internal UAT.

2. Business Value

Removing Barriers to Remote Review

Previously, a clinician needed the full SmartRPD desktop application installed on a Windows workstation to review an AI-generated design. The web client eliminates this constraint: any stakeholder with a browser and credentials can inspect the 3D jaw model, read the 2D RPD design, add comments, and approve or reject work — from a clinic, a mobile device or an external office.

Accelerating Case Turnaround

Case notes, due-date management, inline chat and real-time approval actions are available within the same interface where the design is displayed. Reviewers no longer switch between applications or send files by email to deliver feedback. The integrated workflow shortens the review cycle and reduces the risk of miscommunication between technicians and supervising clinicians.

Extending Platform Reach

A fully responsive design targeting desktop, tablet, and mobile breakpoints means the SmartRPD platform is accessible outside the lab environment. The DOCX report output and the share/export link for the 3D viewer also make it straightforward to include external parties (e.g., referring dentists) in the review without granting them full system access.

3. Major Features Developed

3.1   3D Web Viewer — Shafik Hakim Bin Abdul Wahid

The 3D viewer is a standalone, URL-addressable web page built on Three.js. It loads all geometry, overlay data, and case information directly from the SmartRPD API and renders them in a WebGL scene, enabling full 3D review in any modern browser.

Jaw & Mesh Rendering

Loads upper and lower jaw geometry in OFF and STL formats. Supports framework/denture overlay meshes and alternative STL slots with fallback handling for missing or empty payloads.

Objects Menu

Per-object visibility and opacity sliders for each jaw, surface mesh, polyline set and artificial-teeth set. Undercut and occlusion material modes, vertex/wireframe overlays, and Show All / Hide All controls.

Polyline Rendering & Editing

Loads component guide polylines (Clasps, Rests, Major Connector, Proximal Plate, Mesh, etc.) and renders them colour-coded above the geometry. Draggable point handles with Undo, Redo and Reset.

Artificial Teeth & Guidelines

Loads AI-placed tooth data for both arches, generates scaled mesh proxies in correct jaw-reference space, and renders upper/lower arch guidelines from the placement payload.

Heatmap Analysis

Undercut and occlusion analysis modes applied to jaw objects, with a toggleable colour-band legend describing measurement ranges. Integrated into the responsive viewer toolbar.

Camera & Navigation

Model-centred camera with Front, Rear, Top, Bottom, Left, Right and Centre preset views. Rotation lock/unlock, zoom, and refined touch gestures for tablet and mobile.

Branded Loading Screen

SmartRPD logo, descriptive status text, real download progress bar (14 px, with current-file label and percentage) and smooth fade-out when the scene is ready.

Responsive Toolbar & Shell

Full labelled controls on desktop; compact icon-only controls pinned to the bottom-left on tablet and mobile. Persistent footer showing case name, user, connection state, chat and panel toggle.

Case Chat

Slide-in chat panel in the viewer: text comments, image attachment/upload, image preview, and auto-growing message field. Layout matches the 2D annotation chat for a consistent experience.

2D/3D Review Actions

2D design thumbnail visible in the 3D viewer with enlarged overlay. Approve 2D / Edit 2D / Annotate and Approve 3D / Edit 3D / Add to Mail actions available directly from the viewer interface.

Version History & Navigation

Navigation drawer with case-selection return, Version History modal and account/help entries. Return behaviour restores the originating case-list tab where possible.

Share / Export Entry Point

Export action in case management opens the 3D viewer in a new tab with a temporary encoded identity for auto-login. Direct 3D-viewer icon button (32 × 32 px) per case row in the case list.

3.2   2D Annotation Workspace & Case Workflow — Nyunt

2D Arch Annotation Editor

SVG-based canvas for placing RPD components (clasps, bars, rests, major connectors, proximal plates, mesh) on an AI-generated jaw diagram. Supports both upper and lower arches with tab navigation between components.

Case Management Portal

Case list with search, filtering and instant-paint caching. Case detail panel with actions: open 3D viewer, copy viewer link, export, download (OFF file, 2D JPEG, DOCX report), and view case dashboard.

Case Dashboard

Visual pipeline tracker showing the five processing stages (Jaw Preparation → Six-Point → Segmentation → Polylines → Surface) for each arch, populated from the live API status. Centre panel shows 2D/3D view-capture thumbnails.

Case Notes & Due Dates

Inline case note editor accessible from the annotation workspace. API endpoint integration allows the due date on a case request to be updated directly from the web client.

DOCX Report Generation

Generates a formatted clinical report as a downloadable Word document. Report includes case details, current case-user status, noticeboard captures, and 2D design imagery.

Noticeboard & Viewcaptures

Gallery of 3D view captures (photographs of the 3D model) and 2D drawn views, fetched from the noticeboard API. Used as evidence in the generated report and visible in the case dashboard.

Screen Capture & 3D File Upload

Captures a snapshot of the current 3D preview and posts it to the noticeboard API. Provides a toggle upload button for sending STL files to the case, replacing the earlier modal approach.

Case Creation

Form-driven case creation workflow with validation, linked to the case management portal and the downstream annotation workspace for immediate follow-up actions.

5. Benefits Derived for the Organisation

  • Browser-Only Access to the Full Design Review Workflow
    Clinicians and supervising dentists can inspect the AI-generated 3D jaw model, review the proposed 2D RPD design, and issue approvals or correction requests entirely within a web browser. The SmartRPD desktop application is no longer a prerequisite for the review role, enabling participation from any internet-connected device.
  • Reduced Case Review Turnaround Time
    Inline case chat, annotation, case notes and due-date controls are all accessible on the same screen as the design. Reviewers can communicate corrections and mark approvals without switching applications or sending files externally. This consolidation reduces idle time between submission, review, and revision cycles.
  • Mobile and Tablet Accessibility
    The fully responsive viewer shell and annotation workspace allow clinicians to perform case reviews from tablets at chairside or from personal mobile devices during remote consultations. Compact icon controls, safe-area insets and touch-optimised gestures deliver a functional experience outside the desktop environment.
  • Audit-Ready Clinical Documentation
    The DOCX report generator produces a structured clinical record incorporating case metadata, current workflow status, noticeboard view captures and the 2D design image. This document can be attached to a patient record or submitted to an external reviewer without additional manual preparation.
  • Secure External Sharing Without Account Provisioning
    The Share / Export action generates a time-limited, encoded viewer link. An external stakeholder (e.g., a referring dentist) can be sent a 3D viewer URL and authenticate via that token, viewing the model without holding a permanent SmartRPD account. This extends the reach of collaborative review while preserving access control.
  • Transparent Pipeline Visibility
    The case dashboard maps the backend AI processing stages (jaw preparation, six-point detection, segmentation, polyline generation, surface meshing) to a visual progress indicator. Technicians and managers can see at a glance how far each jaw arch has advanced through the AI pipeline, reducing the need to query individual service logs.
  • Foundation for Continued Product Expansion
    The integration work established a shared component library, a consistent navigation shell, a unified API client layer, and a working CI/CD pipeline (Jenkins + Docker/Nginx). These shared foundations lower the cost of adding new features — such as additional AI analysis modes, richer reporting templates, or real-time multi-user collaboration — in future development cycles.
